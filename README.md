# SmileCare Dental Clinic Website

> Modern, gentle, and precision dental clinic web application crafted with responsive HTML5, Tailwind CSS, and clinical minimalism.

![SmileCare Preview](assets/logo.svg)

## 🌟 Highlights & Features

- **🦷 Opening Animated Tooth Logo & Preloader**: Visual splash animation featuring a glowing tooth contour, dental sparkle glint, and smooth entrance transition.
- **📱 Fully Responsive Design**: Designed fluidly for Mobile, Tablet, and Desktop screens (12-column responsive layout).
- **📅 2-Step Appointment Booking System**:
  - Patient contact details with real-time slot availability.
  - Interactive **Dentition Tooth Map** (patients can tap specific upper/lower teeth to flag sensitivity/pain areas).
  - Dynamic day picker & time slot selector (Morning / Afternoon).
  - Instant booking confirmation modal with generated reference code (`SMILE-XXXXX`).
- **🩺 Comprehensive Treatments Catalog**: 8 dental specialties (General, Whitening, Implants, Root Canal, Aligners, Veneers, Cleaning, Pediatric) with interactive category filters.
- **🔮 3D Smile Experience & Patient Portal**: Biometric jaw twin simulation, bite symmetry analysis, and AI dental diagnostics.
- **🚨 24/7 Emergency Dental SOS**: Instant triage modal with one-click direct hotline calling and tooth trauma first-aid steps.
- **👨‍⚕️ Medical Specialist Profiles**: Board-certified dentist credential cards and experience highlights.

## 🚀 How to Run Locally

Simply double-click `index.html` to open it in any modern web browser. No local build step or npm server required!

## 🌐 Deploying to GitHub Pages

1. In your GitHub repository (`https://github.com/yashh056/dental`), navigate to **Settings** > **Pages**.
2. Under **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
3. Click **Save**. Within 1–2 minutes, your website will be live at:
   `https://yashh056.github.io/dental/`
